# Literature Analysis

This project is a literature analysis of the use of FHIR in the integration of healthcare data.

# Goal
We want to analyze the existing literature on dog-worn sensors and healthcare data interoperability.

The goal is to answer: **How are dog-worn sensors currently used for physiological data collection, and how is this data integrated using healthcare interoperability standards?**

To do this, we'll perform a systematic literature review using Semantic Scholar to:
1.  Identify papers on **dog-worn sensors** and **physiological data**.
2.  Analyze how **FHIR** or other standards are used to **integrate** this data.
3.  Spot gaps and opportunities for **improving interoperability**.

# How to use

With ieee xplorer, we extract the csv with the references after the search of certain terminology.

The used ones are in `search.txt`.

Put the csv into the folder `dataset/`.
